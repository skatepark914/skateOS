3In the Brivo dashboard

Open access.brivo.com in another tab.

1
Find the Webhooks / API Integrations sectionUsually under: Settings → API Management → Webhooks. (Some Brivo plans don't have webhooks — if you don't see it, plan upgrade may be needed.)
2
Create a new webhook subscriptionClick "Add" / "New webhook" / "Subscribe".
3
URL field — paste this exactly
https://zecurmlenxyxanqucrga.supabase.co/functions/v1/brivo-webhook
4
Secret field — paste the secret from Step 1Same secret as Supabase. Brivo signs the webhook with HMAC-SHA256 using this. If they differ, skateOS rejects every event.
5
Event filter — select these:
access_granted access_denied door_held_open door_forced user_created user_deleted

Bold = required. Green = optional but useful (intrusion alerts). Strikethrough = skip (handled separately).

6
Save the webhookBrivo may want to test it. If it fails, check the URL has no trailing slash and the secret matches exactly.

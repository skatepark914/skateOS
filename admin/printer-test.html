Hey Jon — when you're at the front desk anyway, run this. Takes ~10 min. Tells us if the existing thermal printer plays nice with skateOS, or if we need a driver tweak or a new printer before cutover.

Steps

1
Open this page on the front-desk iPadTap the "Print test receipt" button below. Your browser's print dialog opens with the thermal printer pre-selected (if it's the system default).
2
Print to the thermal printerPick the Star or Epson printer in the dialog. Use the "80mm receipt" paper size if it's an option.
3
Check the paper that comes outLook for: header lines, line-item rows, subtotal/tax/total math, the "thanks" footer. Each row should be readable.
4
Fill out the form belowEven a quick "yep it works" is enough. Anything weird, snap a photo + describe what you saw.

What this tests

A
80mm thermal widthThe receipt is sized for standard thermal rolls. If it overflows the paper, we have a width problem.
B
Monospace alignmentTwo-column rows (item + price) need to line up. If they don't, the cashier can't read the totals at a glance.
C
Dashed dividersIf the printer can't render dashed lines, sections smush together.
D
Cut + feedDid the printer cut the paper at the right spot, or did you have to tear it manually?

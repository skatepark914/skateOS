skateOS · Square Direct Import

Pull everything from Square — including photos

Hits Square's API directly to grab the full product catalog (with image URLs), customers, categories, and variations. Much richer than CSV import. Drop a Square Personal Access Token in once + run.

1Generate a Square access token

1
Open Square Developer Dashboard developer.squareup.com/apps → log in with same Square account that has 2nd Nature.
2
Create app (or pick existing)Click "+ Create your first application" → name it "skateOS importer" → click Create.
3
Switch to "Production" modeTop of app page — toggle from Sandbox to Production. Sandbox tokens won't see your real data.
4
Copy the "Access token"Starts with EAAA... — long string. Don't share it publicly; treat it like a password.

2Set the token in Supabase

Run this in your Terminal, replacing the placeholder with your real token:

supabase secrets set SQUARE_ACCESS_TOKEN=EAAA_YOUR_TOKEN_HERE --project-ref zecurmlenxyxanqucrga
Owner-only. Skip this if I (Claude) already set it for you — text it to me and I'll set it remotely.

3Preview what'll be pulled

Dry-run mode. Counts what's available in Square without writing anything to skateOS. Use this to confirm the token is valid + sane data is there.

4Commit the import

Writes to skateOS. Products + categories + customers get inserted. Duplicates by SKU / email / phone are skipped automatically. Photos are linked by URL (not re-uploaded — they stay on Square's CDN).

Idempotent: Safe to re-run — duplicates skip rather than double-insert. New items from Square get added on subsequent runs.

5Sales history (orders)

Pull past Square sales into the skateOS sales + sale_items tables. Default window: last 12 months. Idempotent — re-runs skip already-imported orders via the Square order_id dedupe key.

Heads up: Big windows take time. The importer pulls up to 15,000 orders per call (~30 paginated chunks × 500). If there's more, it returns a next_cursor — click the button again to continue from where it stopped.
Leave blank for "last 12 months". Pick a specific date to import a narrower window.

6What gets imported

📦
ProductsSquare's catalog ITEM objects flattened to one skateOS product per variation. Includes name, description, SKU, price, image URL, and Square category. Inventory quantity defaults to 0 (Square's stock API needs a separate Locations pull, not included v1).
🏷
CategoriesSquare CATEGORY objects → skateOS categories rows. Case-insensitive dedup against existing.
🖼
ImagesSquare IMAGE objects URLs captured + attached to the right product via image_ids. Images stay hosted on Square's CDN (no re-upload).
👥
CustomersName, email, phone, address, DOB (if filled), notes. Dedup by email then by last-10-digits of phone.
⊘
Not yet imported (v1)Inventory counts (separate Square API call per location), order history, loyalty point balances, gift card balances. Add later if needed.

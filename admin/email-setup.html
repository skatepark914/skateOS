skateOS · Email Setup

Wire up email for 2ntr.com

Without DNS verification, every email skateOS sends — receipts, lesson reminders, renewal nudges, birthday greetings — lands in spam. This page walks you through the ~15 min setup once. Live DNS check at the bottom tells you when records have propagated.

Why this matters: 80% of skateOS's CRM features depend on emails landing in inboxes. If DNS isn't verified, customers stop seeing receipts and you look unprofessional. Same-day fix in GoDaddy + Resend.

1Sign up for Resend (if not done)

1
Create a Resend accountGo to resend.com/signup. Free up to 3,000 emails/month — more than enough for 2nd Nature.
2
Skip onboarding survey if asked"Build an app" → "Just send me the dashboard" works.

2Add 2ntr.com domain in Resend

1
Navigate to resend.com/domainsClick "Add Domain".
2
Enter "2ntr.com" — no subdomainThis lets you send from any address @2ntr.com (info@, hello@, support@).
3
Region: pick US East (Virginia)Closest to your customers. Lower latency on send.
4
Resend shows you 3 DNS recordsSPF (TXT), DKIM (TXT or CNAME), DMARC (TXT). Leave this tab open — you'll need the exact values for the next step.

3Add DNS records in GoDaddy

1
Open GoDaddy DNS managementFind 2ntr.com → click DNS / Manage DNS.
2
For each Resend record, click "Add New Record"Match the Type (TXT or CNAME), Name (sometimes called Host), and Value (sometimes called Data or Points To) exactly. TTL leave at default (1 hour).
3
Common gotchas
  • →If Resend's "Name" is resend._domainkey, GoDaddy might want you to type just resend._domainkey (not the full resend._domainkey.2ntr.com). Don't include the domain suffix.
  • →If Resend's "Name" is just @ or blank, in GoDaddy use @ for the root domain.
  • →SPF: if you already have a TXT record starting with v=spf1, don't add another one. Edit the existing one to add include:_spf.resend.com before ~all.
  • →Save after each record.
4
Wait 5-15 min for propagationGoDaddy says "instant" but it's usually 5-15 min. Use the DNS check below to verify.

4Verify in Resend

1
Back in Resend → Domains → 2ntr.comClick "Verify DNS records". If all 3 show green ✓, you're done.
2
If any are red ✕Wait another 5 min and click "Verify" again. DNS can be slow. If still red after 20 min, double-check the record values in GoDaddy match Resend exactly.

6Send a test email (when verified)

Once Resend shows all 3 records green, fire a test email through skateOS to confirm the full pipeline.

7Set the Resend API key in Supabase

Skip this if already done. Once Resend shows your domain verified, generate an API key + put it in Supabase secrets.

1
In Resend: resend.com/api-keysClick "Create API Key" → name "skateOS" → permission "Full access" → copy the key (starts with re_).
2
Run in your Terminal:
supabase secrets set RESEND_API_KEY=re_YOUR_KEY_HERE --project-ref zecurmlenxyxanqucrga
Replace re_YOUR_KEY_HERE with the key from Resend.
